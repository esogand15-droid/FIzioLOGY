# render/ — ساخت PDF جزوهٔ مادر

## اجرا

```bash
/home/user/.venv/bin/python render/build_master.py      # → HumsYar_Neuro_Special_Senses_Master.pdf
/home/user/.venv/bin/python render/qa_report.py         # → reports/S01_QA_REPORT.md
```

`build_master.py` دو بار می‌سازد: پاس اول صفحهٔ هر لنگر را کشف می‌کند، پاس دوم
فهرست را با همان شماره‌ها می‌نویسد و اگر شماره‌ها بین دو پاس جابه‌جا شوند،
اسکریپت با خطا متوقف می‌شود (بدون فهرست غلط). در پایان، اگر صفحهٔ آخر کاملاً خالی
باشد حذف می‌شود.

پیش‌نیازها (در `requirements.txt` ریشهٔ مخزن):

```
reportlab  pypdf  pypdfium2  Pillow  arabic-reshaper  python-bidi  fonttools  uharfbuzz
```

`pypdfium2` فقط برای QA و رندر تصویری صفحه‌ها لازم است، نه برای ساخت PDF.
`uharfbuzz` فعلاً استفاده نمی‌شود و برای کار باز «لایهٔ متنی قابل کپی» نصب شده است.

## معماری

| فایل | نقش |
| --- | --- |
| `pdf_kit.py` | موتور چیدمان RTL: `PDFBook` (کاور تیره، h1/h2/h3، پاراگراف تراز‌شده، فهرست، جدول شکسته‌شونده، جعبهٔ نکته، کادر یادداشت، شکل و تصویر صفحهٔ اصلی، بلوک ارجاع گایتون). مختصات از **بالا به پایین** است؛ `py(y)` تبدیل به مختصات PDF می‌کند. |
| `build_master.py` | محتوا را از `content/` و `work/references/` می‌خواند، جلد/شناسنامه/نقشهٔ تقسیم کار/فصل/پیوست‌ها را می‌سازد. |
| `qa_report.py` | پنج دروازهٔ ماشینی؛ کد خروج ۱ اگر خطای سخت باشد. |

### شکل‌دهی متن

1. `fa_digits()` ارقام لاتین را به فارسی تبدیل می‌کند (توکن‌های لاتین دست‌نخورده).
2. `shape()` = `arabic_reshaper.reshape` + `python-bidi.get_display` → رشته در
   **ترتیب دیداری**.
3. `runs()` رشته را به بازه‌های فونت تقسیم می‌کند: هر نویسه‌ای که در Vazirmatn
   نباشد (حروف یونانی، فلش‌ها) با DejaVu Sans کشیده می‌شود. بدون این کار،
   `α1` و `β` و `←` بی‌صدا حذف می‌شدند.
4. عرض هر خط با `text_width()` (مجموع عرض بازه‌ها) اندازه‌گیری می‌شود، نه با
   `stringWidth` تک‌فونت؛ وگرنه شکست خط و تراز‌سازی دوطرفه غلط می‌شد.

### محدودیت شناخته‌شده

متن فارسی در لایهٔ متنی PDF به شکل گلیف‌های شکلیافته (U+FE70..U+FEFF) در ترتیب
دیداری ذخیره می‌شود. نمایش و چاپ درست است، اما کپی/جست‌وجو در فایل به‌هم‌ریخته
می‌شود. QA به همین دلیل «حضور نویسه‌ها» را می‌سنجد، نه ترتیب جمله‌ها. رفع کامل
نیازمند نگاشت `ActualText`/`ToUnicode` با هارف‌باز است.

## قرارداد محتوا (`content/sessions/*.json`)

هر فایل یک آرایه از موضوع‌ها:

```jsonc
{
  "topic_id": "s01-T04",
  "title": "…",
  "prerequisites": [{"id": "s01-T03", "level": "مرور پیشنهادی", "reason": "…"}],
  "blocks": [ /* انواع زیر */ ]
}
```

| `type` | فیلدهای لازم | نکته |
| --- | --- | --- |
| `p`, `ul`, `ol` | `text` یا `items` + **`src`** | `src` اجباری است؛ QA بدون آن خطا می‌دهد. |
| `h3` | `text` | زیرمبحث سطح ۳. |
| `callout` | `text`, `kind` (`key`/`exam`/`warn`/`info`), `src` | جعبهٔ نکته. |
| `figure` | `asset`, `caption`, `src` | مسیر نسبت به ریشهٔ مخزن؛ باید در `images/INDEX.json` باشد. |
| `facsimile` | `asset`, `caption`, `src` | تصویر صفحهٔ اصلی جزوهٔ ۱۴۰۲. |
| `note` | `size` (`small`/`medium`/`large`), `title`, اختیاری `tag` | کادر خالی برای نوشتن. |
| `guyton` | `title`, `sections`, `note`, اختیاری `max_chunks`/`per_chunk` | متن انگلیسی عیناً از `work/references/guyton_ch45_excerpts.json`. |
