## ۲. ساختار جلد (همان قالب شش جلد پیشین)

جلد → راهنمای خواندن و قاعدهٔ ارجاع → فهرست یک‌صفحه‌ای (با شمارهٔ صفحهٔ واقعی و پیوند) → نقشهٔ جلسه و منابع → ۲۰ مبحث در ۴ خوشه → خلاصهٔ استاد → پیوست مقابله با ۱۴۰۲ → آزمون ۲۰ سؤالی استاد + پاسخ‌نامه → چک‌لیست پذیرش + خودآزمایی با پاسخ → جلد پشت.

هر مبحث: شناسنامه (جای مبحث، هدف، پیش‌نیاز، راهنمای خواندن، منابع) → متن درس با ارجاع موضعی → جدول یا شکل → کادر توضیحی/بالینی → کادر مرجع (در مباحث دارای مرجع) → یادداشت خط‌دار → برگهٔ تحویل.
