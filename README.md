# FIzioLOGY — جزوهٔ مادر فیزیولوژی اعصاب و حواس ویژه

سند مرجع تیم یادداشت‌نویسی درس فیزیولوژی اعصاب و حواس ویژه (دکتر خوارزمی).
هدف: نگه‌داشتن کل محتوای منابع در یک ساختار واحد و قابل تقسیم بین اعضای تیم —
نه جزوهٔ عمومی دانشجویی.

- هر جلسه یک سند جداگانه (هیچ فایلی جای‌گزین جلسهٔ قبل نمی‌شود):
  - جلسهٔ ۱ — **`pdf/HumsYar_Neuro_Jalase1.pdf`** (۶۴ صفحه)
  - جلسهٔ ۲ — **`pdf/HumsYar_Neuro_Jalase2.pdf`** (۵۷ صفحه)
  - جلسهٔ ۳ — **`pdf/HumsYar_Neuro_Jalase3.pdf`** (۵۹ صفحه)
  - جلسهٔ ۴ — **`pdf/HumsYar_Neuro_Jalase4.pdf`** (۶۰ صفحه)
  - جلسهٔ ۵ — **`pdf/HumsYar_Neuro_Jalase5.pdf`** (۷۶ صفحه)
- نسخهٔ اولیه جلسهٔ ۱ با نام **`HumsYar_Neuro_Special_Senses_Master.pdf`** هم دست‌نخورده نگه داشته شده است.
- وضعیت دقیق کار: **`PROJECT_STATUS.md`**
- گزارش کنترل کیفیت (خودکار): **`reports/S01_QA_REPORT.md`**، **`reports/S02_QA_REPORT.md`**، **`reports/S03_QA_REPORT.md`**، **`reports/S04_QA_REPORT.md`**، **`reports/S05_QA_REPORT.md`**
- فهرست دارایی‌ها و منابع: **`INVENTORY.md`**

## ساخت دوبارهٔ PDF

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python render/build_master.py --session s02   # PDF همان جلسه
.venv/bin/python render/qa_report.py --session s02      # گزارش کیفیت (کد خروج ۱ = خطای سخت)
```

توضیح معماری، قرارداد فایل‌های محتوا و چک‌لیست بازبینی علمی: `render/README.md`.

## ساختار مخزن

| مسیر | محتوا |
| --- | --- |
| `content/outline/` | نقشهٔ مباحث، پیش‌نیازها، نگاشت صفحه؛ منبع ساخت فهرست و پیوست‌ها |
| `content/sessions/` | متن تألیف‌شده به تفکیک مبحث (JSON، هر بلوک با ارجاع صفحه) |
| `render/` | موتور چیدمان RTL، اسکریپت ساخت، اسکریپت QA |
| `pdf/` | سند نهایی هر جلسه با نام مستقل خودش (`HumsYar_Neuro_Jalase1.pdf`، `Jalase2` …) |
| `work/extraction/` | خروجی خام استخراج متن/شکل (دست‌نخورده، برای بازبینی) |
| `work/references/` | گایتون: نمایهٔ فصل‌ها و جملات صفحه‌گرفته‌شده |
| `work/drafts/` | پیش‌نویس‌های صفحه‌محور هر مبحث (ورودی تألیف) |
| `work/scripts/` | ابزارهای استخراج، بازسازی متن فارسی، کنترل کیفیت |
| `images/` | شکل‌های استخراج‌شده و تصویر صفحات جزوهٔ ۱۴۰۲ + `INDEX.json` |
| `assets/fonts/` | Vazirmatn + DejaVu Sans (فال‌بک) و سند منشأ فونت |
| `reports/` | گزارش‌های QA و بازیابی |
| `فیزیولوژی اعصاب حواس ویژه/` | فایل‌های اصلی منبع (بخشی از آن‌ها LFS pointer) |

## قواعد کار

- ادعای «کامل شد» فقط با شاهد در `INVENTORY.md` و گزارش پوشش.
- جمله‌های منبع بازنویسی معنایی نمی‌شوند؛ هیچ عدد/صفحه/نقل‌قولی ساخته نمی‌شود.
- گایتون در کادر جداگانه و با ارجاع فصل/صفحه می‌آید و به استاد نسبت داده نمی‌شود.
- خروجی ASR تا بازبینی، «پیش‌نویس تأییدنشده» است و وارد متن علمی نمی‌شود.
- فایل‌های بزرگ در Google Drive می‌مانند؛ مخزن فقط کد، فهرست، گزارش و سند را نگه می‌دارد.
