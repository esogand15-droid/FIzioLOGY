# استاندارد محتوایی جزوه‌های آناتومی

تاریخ: ۱۴۰۴/۰۸/۰۴ · این سند **قرارداد** است؛ هر جلسه پیش از تألیف باید با آن تطبیق داده شود.

---

## ۱. اصل حاکم

> در فیزیولوژی، «متنِ استاد + متن گایتون با ترجمه» ستون محتوا بود. در آناتومی، **شکل مرجع خودش محتواست**؛
> هر مفهوم تشریحی باید کنار تصویری از مرجع بنشیند که همان ساختار را نشان می‌دهد — دقیقاً همان‌طور که
> متن انگلیسی گایتون عیناً نقل و سپس ترجمه می‌شد.

پیاده‌سازی فنی: بلوک تازهٔ `anatplate` (هم‌ارز `guytonpair`) با این ساختار:

```jsonc
{
  "type": "anatplate",
  "title": "سطح مقطع نخاع در قطعهٔ سینه‌ای",
  "book": "snell",                 // snell | grays
  "chapter": "4",
  "file_page": 352,                // شمارهٔ صفحهٔ فایل (نه چاپی)
  "fig_no": "4-15",
  "view": "مقطع عرضی، نمای فوقانی",   // نما و جهت
  "asset": "images_anatomy/snell_ch04_fig15.png",
  "labels": [["Dorsal horn","شاخ خلفی"],["Gracile fasciculus","دستهٔ نرمه"]],
  "caption_en": "Light to moderate staining…",
  "fa": "توضیح فارسی تحریریه که ساختار و ارتباطش را می‌گوید.",
  "src": "جزوهٔ جلسهٔ ۳، ص ۱۲"
}
```

قواعد این بلوک:

1. `caption_en` **عیناً** از مرجع (بدون تغییر واژه) — برای Gray's از OCR بازبینی‌شده.
2. `fa` ترجمه/توضیح **تحریریه** است و هرگز به‌عنوان جملهٔ نویسندهٔ کتاب ارائه نمی‌شود.
3. `fig_no` و `file_page` اجباری‌اند؛ بدون آن‌ها بلوک در QA رد می‌شود.
4. `labels` باید همهٔ برچسب‌های مهم شکل را در بر بگیرد؛ در متن فارسی به شکل ارجاع داده می‌شود.

## ۲. اصول نگارش فارسی

| اصل | مثال درست | مثال نادرست |
| --- | --- | --- |
| اصطلاح لاتین در نخستین کاربرد | «شاخ خلفی (dorsal horn)» | «قرنیهٔ پشتی» بدون معادل |
| یکدستی نام ساختار در کل جزوه | همیشه «دستهٔ نرمه (gracile fasciculus)» | یک‌بار «فاسیکولوس گراسیلیس»، یک‌بار «دستهٔ نرمه» |
| دقت جهت و رابطه | «در سطح پل، در بخش خلفی…» | «بالای پل» (مبهم) |
| تفکیک ساختارهای مشابه | جدول افتراقی برای شاخ خلفی/قدامی در سطوح مختلف | توضیح یک‌کاسه |
| توضیح گام‌به‌گام مسیر | مبدأ → مسیر → تقاطع → سیناپس → مقصد → کارکرد | یک پاراگراف فشرده |
| بدون تشبیه غیرضروری | — | «مغز مثل یک کامپیوتر…» |
| بدون تکرار بین جلسات | ارجاع متقابل: «در S2 دیدیم…» | بازنویسی کامل |

## ۳. ساختار ثابت هر جلسه (هم‌راستا با فیزیولوژی)

| ترتیب | بلوک | هم‌ارز در فیزیولوژی |
| --- | --- | --- |
| ۱ | جلد تیره + فصل/جلسه | `cover_page` |
| ۲ | شناسنامهٔ سند (منابع، نحو استفاده) | `front_matter` |
| ۳ | فهرست مطالب دوپاس | TOC |
| ۴ | نقشهٔ مباحث و پیش‌نیازها | `work_division` |
| ۵ | برای هر مبحث: `idcard` → متن → `anatplate`‌ها → جدول → `callout` → `note` → `handoff` | همان |
| ۶ | «چک‌لیست ساختارهای کلیدی» هر جلسه (جدول فارسی/انگلیسی) | تازه، مخصوص آناتومی |
| ۷ | نقشهٔ جلسات آینده | `roadmap` |

**ممنوع:** تولید بخش‌های تکراری فقط برای پر کردن قالب. اگر مبحثی جدول لازم ندارد، جدول نمی‌گیرد.

## ۴. استاندارد تصویر نوروآناتومی (بخش بحرانی این پروژه)

### ۴.۱ انتخاب تصویر

| معیار | الزام |
| --- | --- |
| مرتبط بودن | تصویر باید همان ساختار/سطحی را نشان دهد که متن همان صفحه می‌گوید |
| نما و جهت | `view` پر شود: نمای خارجی/مقطع کرونال/ساژیتال/افقی + جهت (فوقانی/تحتانی) |
| خوانایی برچسب | برچسب‌ها در اندازهٔ چاپ A4 خوانا باشند؛ وگرنه شکل رد می‌شود |
| رزولوشن | حداقل ~۹۰۰ px در بُعد بزرگ‌تر (شکل‌های جدا Snell و Gray's این را دارند؛ **برش از لایهٔ صفحهٔ ۱۳۶dpi مجاز نیست**) |
| برچسب تکراری | شکل بدون برچسب فارسی معرفی‌شده در متن پذیرفته نمی‌شود |
| مجوز | تا تعیین تکلیف حق بازنشر (ف۲ `audits/NEUROANATOMY_REFERENCE_AUDIT.md` §۶)، فقط استفادهٔ داخلی/آموزشی |

### ۴.۲ قواعد درج در PDF

1. هر شکل **کپشن فارسی + شمارهٔ شکل مرجع + صفحهٔ مرجع** دارد (مثل «شکل ۴-۱۵ اسنل، ص ۳۵۲ فایل»).
2. ارجاع در متن اجباری است: «(شکل ۳ را ببینید)» — شکل بدون ارجاع در متن ممنوع.
3. نسبت ابعاد حفظ می‌شود؛ بزرگ‌نمایی مصنوعی ممنوع (قاعدهٔ پروژهٔ فیزیولوژی).
4. اگر برچسب‌های تصویر انگلیسی‌اند، معادل فارسی **زیر شکل در جدول برچسب‌ها** می‌آید، نه روی تصویر
   (تا تصویر شلوغ نشود).
5. تصویر روی صفحه نباید از ۱۵۰mm بلندتر شود و نباید باعث بریدگی متن شود.

### ۴.۳ آنچه ممنوع است

- تصویر تولیدشده با هوش مصنوعی به‌عنوان «شکل آناتومی» (فیزیولوژی هم یک نمونهٔ پرترهٔ AI را کنار گذاشت).
- برش تصویر از اسکن صفحهٔ کم‌رزولوشن.
- حذف/بازکشیدن برچسب‌های شکل مرجع بدون ثبت.
- نسبت دادن شکل به استاد وقتی از کتاب است (و برعکس).

## ۵. تفکیک سه لایهٔ محتوا (همان مدل فیزیولوژی)

| لایه | نشانه بصری | منبع |
| --- | --- | --- |
| متن آموزشی تألیفی | پاراگراف معمولی | نگارش تیم، مبتنی بر جزوهٔ استاد |
| نقل مرجع | کادر `anatplate` (شکل + کپشن انگلیسی + ترجمهٔ تحریریه) | Snell/Gray's با شمارهٔ صفحه |
| نکتهٔ بالینی/امتحانی | `callout` با `kind: exam` یا `kind: warn` | Clinical Correlation در Snell یا جزوه |

جمع‌بندی هر مبحث در `handoff` و جای یادداشت دستی در `note`.

## ۶. کنترل پیش از «متن آماده»

- [ ] هر پاراگراف `src` دارد (شمارهٔ صفحهٔ جزوه).
- [ ] هر مفهوم تشریحی حداقل یک `anatplate` دارد یا در `handoff` دلیل نبودش ثبت شده.
- [ ] جدول برچسب‌ها کامل است.
- [ ] اصطلاح‌ها با فهرست واحد جلسه یکدست‌اند.
- [ ] هیچ جمله‌ای از مرجع بدون کادر و ارجاع نقل نشده.
- [ ] اختلاف جزوه و مرجع ثبت شده (نه حل سلیقه‌ای).
