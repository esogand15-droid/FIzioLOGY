## ۰. از کجا آمدند (فاز صفر)

هر دو مرجع در شاخهٔ `main` مخزن، داخل پوشهٔ `علوم تشریح دستگاه اعصاب/` هستند — نه در شاخهٔ کاری فیزیولوژی:

```bash
git ls-tree -r --name-only main -- "علوم تشریح دستگاه اعصاب"
# 21 فایل: 7 فایل مرجع (Snell + 6 پارهٔ Gray's) + 14 PDF جزوهٔ درس
```

مخزن **partial clone** است؛ `git cat-file` روی اشیای باینری شکست می‌خورد و فقط `git show` کار می‌کند:

```bash
git -c core.quotepath=false show "main:علوم تشریح دستگاه اعصاب/<file>.pdf" > out.pdf   # ✔
```

هیچ فایل مرجعی LFS pointer نبود؛ همهٔ ۷ فایل PDF واقعی و سالم باز شدند (هدر `%PDF-1.6/1.7`).

## ۶. محدودیت‌ها و مواردی که با چشم بررسی نشده

1. **حق تکثیر تصاویر:** فایل‌های مخزن از منابع کتابخانهٔ سایه (نام فایل Snell شامل `z-library`/`1lib` و
   متادیتای `BOOKSMEDICOS.ORG`) تهیه شده‌اند. برای انتشار عمومی جزوه، مجوز بازنشر شکل‌ها از
   Wolters Kluwer و Elsevier **حل نشده** است؛ این موضوع باید پیش از انتشار بیرونی تصمیم‌گیری شود.
   (این سند دربارهٔ مجاز بودن استفادهٔ آموزشی داخلی ادعایی نمی‌کند؛ فقط واقعیت فایل را ثبت می‌کند.)
2. **ویرایش Gray's:** فایل **۳rd edition** است، در حالی که اطلاعات ناشری که شما دادید ویرایش **۵th**
   (۲۰۲۴، ۱۱۶۸ ص) است. تفاوت نسخه‌ها در طرح درس باید صریح علامت بخورد.
3. **همهٔ ۱٬۱۸۹ صفحهٔ Gray's با چشم بررسی نشده**؛ فقط صفحات نمونه (۶۳، ۹۵، ۹۶، ۱۰۰، ۱۵۰) باز و رندر شد.
4. **شمارش «شکل»ها در Gray's تقریبی است:** ۳٬۴۶۳ XObject غیرتمام‌صفحه اندازه‌گیری شد، ولی بخشی از آن‌ها
   نوارهای برچسب (مثل ۵۰۹×۳۵) هستند؛ گروه‌بندی و حذف تکراری انجام نشده است.
5. **کیفیت رستر ۱۳۶ dpi** در لایهٔ صفحه: شکل‌های جدا رزولوشن بالاتری دارند (۱۰۵۳×۶۸۷) و همین‌ها باید
   مبنای استخراج باشند، نه برش از لایهٔ صفحه.
6. **OCR فقط روی ۵ صفحه آزمایش شد** (۹٫۳ ثانیه/صفحه)؛ پوشش کامل OCR برای Gray's «طراحی‌شده و آزمون‌شده»،
   نه «اجراشده».
